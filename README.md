# Noxera - Premium Streetwear

A modern, premium e-commerce web application for Noxera, a high-end streetwear brand. Features a custom glassmorphism design system, smooth scroll animations, and cinematic UI interactions.

---

## 🚀 Features

*   **Cinematic Hero & Animations**: High-impact video sections, full-bleed imagery, and custom `motion/react` scroll animations (ScrollGrid parallax).
*   **Premium Product Displays**: Box-fit streetwear pieces presented in modern product cards with hover interactions and wishlist functionality.
*   **Categories & Drops**: Dedicated sections for Hoodies, Box Fit Tees, Bottoms, and special "Limited Drops".
*   **Branch Locator**: Information for physical store branches (e.g., Port Said) with integrated Maps and WhatsApp links.
*   **Interactive UI**: Modern glassmorphic components, fluid navigation, and premium typography (Oswald).

## 🛠️ Technology Stack
*   **Frontend**: React (Vite)
*   **Styling**: Tailwind CSS & Vanilla CSS
*   **Animations**: Motion (formerly Framer Motion)
*   **Icons**: Lucide React
*   **Routing**: React Router v7+
